# Gym Care

Журнал тренувань: День А і День Б, запис підходів, правки, історія і редактор програми. Дані лежать у браузері (IndexedDB). Працює як PWA (маніфест + service worker у production).

Потрібен Node.js `^22.22.3`, `^24.15.0` або `>=26`. Поточний системний Node 24.14.1 для Angular 22 замалий.

```bash
npm start
```

Відкрий `http://localhost:4200`.

Щоб глянути з телефона в тій самій мережі (без офлайн-кешу SW):

```bash
npm run start:lan
```

Production-збірка з service worker (офлайн і «Додати на екран Домой»):

```bash
npm run start:pwa
```

Відкрий `http://localhost:4173`.

Публічна HTTPS-збірка (GitHub Pages): [https://vbomba.github.io/gym-care/](https://vbomba.github.io/gym-care/).  
На iPhone у Safari: Поділитися → На екран «Домой». Кожен push у `main` оновлює сайт через Actions.

### Синхронізація

Локальна IndexedDB лишається робочою копією. Між пристроями ходить один JSON (`SyncBundle`): програма, завершені сесії, tombstone видалень. Активне тренування не синкається.

Без сервера: вкладка **Синк** → експорт / імпорт JSON.

З міні-сервером:

```bash
npm run sync-server
```

За замовчуванням: `http://localhost:8787`, токен `dev-sync-token` (змінюй через `SYNC_TOKEN`). У застосунку вкажи URL без шляху (`http://localhost:8787`) і токен, натисни «Синхронізувати». Після завершення тренування й при появі мережі клієнт пробує sync сам.

Програма сідає в базу з `data/program.json` лише коли база порожня. Щоб побачити файл знову, очисти дані сайту в браузері.
